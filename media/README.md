# Media assets

`ne_110m_coastline.geojson` is the public-domain Natural Earth 1:110m
coastline dataset. FlexCTM bundles this coarse dataset so post-processing can
draw coastlines without network access.

Source: <https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_coastline.geojson>
